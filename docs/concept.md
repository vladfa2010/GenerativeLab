# Продуктовая концепция

## Лифт-питч

Zoom показывает, кто говорит. Мы показываем, что команда думает.

Соцсеть для одного звонка: каждый тезис — узел, к которому цепляются голоса, возражения и статусы.

## Ключевые механики

### 1. Тезис как центральный объект
Модератор публикует тезисы на общую доску (в ручном режиме — из личных заметок одним кликом).
Карточка тезиса содержит: текст, автора, статус, голоса, цепочку комментариев.

### 2. Голосование +1 / −1 / 0
Три состояния покрывают почти все реакции, цена действия — один клик:
- **+1** — согласен
- **−1** — возражаю
- **0** — услышал, воздерживаюсь / мне нужно время

Массовая «0» по тезису — сигнал, что решение навязано, а не принято. Это аналитика для руководителя.

### 3. Статусы тезисов
Черновик → На голосовании → Финализировано (или отклонено).
Явный статусный переход превращает хаос разговора в артефакт с чётким концом.

### 4. Цепочки контраргументов
Под каждым тезисом — ветка комментариев. Решает боль «не успел вклиниться в речь»:
у каждого тезиса есть вечная открытая ветка, живущая и после встречи.

### 5. Идентичность при входе
Участник заходит по ссылке, сам указывает имя и отдел. Без регистрации — порог входа около 5 секунд.
Отдел показывается рядом с именем и в будущем даёт фильтр голосов по отделам
(«все четыре −1 от разработки — это не спор, это блокер ресурса»).

## Режимы участия

- **Модератор** — ведёт тезисы: личные заметки (видит только он) + общая доска.
- **Участник** — только доска: голосует, комментирует.

## Границы реалтайма

- Во время звонка: голосование и короткие реакции (микродействия, реально выполнимые параллельно со слушанием).
- После встречи: развёрнутые комментарии и оспаривание (когда тезисы зафиксированы и можно спокойно думать).

Не пытаться заставлять людей писать эссе под звук чужих голосов.

## Риски и ответы

| Риск | Ответ |
|---|---|
| Модератор отвлечётся, всё умрёт | AI-черновики тезисов из транскрипта (этап 2); роль модератора сводится к «пинать», а не «писать» |
| Голосование «под глазами начальника» | Опция отложенного показа результатов / анонимное голосование |
| Самозаявленные имя и отдел можно подделать | Для MVP некритично; позже — доменный email / SSO для корпоративного тарифа |
| Перебивки и одновременная речь | Тезис важнее атрибуции; точность спикера — не блокер |

## Целевая аудиенция (первые клиенты)

Продуктовые команды и агентства 10–50 человек, где дейлики и брейнштормы — ежедневная боль,
а руководитель сам чувствует, что «зумы растекаются». Уже записывают встречи, но записи никто не смотрит.
