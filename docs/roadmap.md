# Дорожная карта MVP

## Этап 0 — ручной режим (сейчас)

- [x] Интерактивный мокап второго окна (вход, роли, доска, голоса, комментарии)
- [ ] Бэкенд: комнаты, тезисы, голоса, комментарии (API + WebSocket)
- [ ] Живая синхронизация мокапа с сервером (вместо локальной симуляции)
- [ ] Развёртывание на VPS

Критерий готовности: реальная встреча 5–8 человек, модератор ведёт тезисы руками,
все голосуют с своих устройств, после встречи сохраняется карта тем.

## Этап 1 — устойчивость ручного режима

- [ ] Панель модератора: очередь неразобранных реплик-транскрипта нет — ручные заметки остаются
- [ ] Подсветка «кто из приглашённых ещё не проголосовал»
- [ ] Итоговая страница встречи: карта тем, финализированные решения, расхождения по отделам
- [ ] Retention и экспорт (PDF/Markdown)

## Этап 2 — локальный агент транскрипции

- [ ] Захват системного звука (macOS BlackHole, Windows WASAPI loopback)
- [ ] faster-whisper + Silero VAD, нарезка на реплики
- [ ] Кластеризация спикеров + ручная атрибуция имён
- [ ] Стриминг текстовых сегментов на сервер по WSS

Критерий: модератор нажимает «записывать», реплики появляются в его окне автоматически.
Аудио не покидает устройство.

## Этап 3 — AI-черновики тезисов

- [ ] Предложение тезисов из потока реплик (LLM)
- [ ] Кластеризация тем: доска сама предлагает «похоже, это одна тема»
- [ ] Роль модератора сводится к «пинать / править», а не «писать»

## Этап 4 — аналитика для руководителей

- [ ] Фильтр голосов по отделам
- [ ] Отчёты по встречам: доля финализированных тезисов, системные расхождения отделов
- [ ] Корпоративный тариф: доменный email / SSO

## Метрики

- Доля встреч, после которых участники оставили хотя бы один голос
- Доля тезисов, дошедших до статуса «Финализировано»
- Время от публикации тезиса до первой реакции команды
